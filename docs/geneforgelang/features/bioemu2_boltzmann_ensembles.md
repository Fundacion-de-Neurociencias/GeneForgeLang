# BioEmu2 Boltzmann Conformational Ensembles & Cryptic Pocket Operators

## Overview

Traditional structural biology tools (AlphaFold 3, ESMFold, Chai-1) predict a static snapshot corresponding to an apparent ground-state crystal structure. However, in cellular biophysics—and particularly in neurodegeneration (Tau, TDP-43, $\alpha$-synuclein) and GPCR allosteric signaling:
1. **Proteins exist as thermodynamic Boltzmann ensembles** continuously sampling metastable conformations.
2. **Pathogenic interfaces and druggable cryptic pockets** are transiently exposed ($P_{\text{Boltzmann}} \ge 0.05$) while remaining sterically occluded or collapsed in apo ground states.
3. **Biological binding operates by conformational selection**, wherein nanobodies (VHH) or allosteric modulators shift the equilibrium toward functional active states.

Inspired by **Microsoft Research AI for Science's BioEmu2** (open weights, MIT license, 2026), GeneForgeLang (GFL) elevates structural representation from static single-model coordinates to **first-class thermodynamic Boltzmann ensembles** with relative free energy accuracy ($\sim 1\text{ kcal/mol}$).

## Canonical Data Contracts (`src/geneforgelang/core/gftypes.py`)

### 1. `BoltzmannEnsembleContract`
Represents an equilibrium conformational distribution generated by stochastic generative models (`bioemu2`, `molecular_dynamics`).

```python
@dataclass
class BoltzmannEnsembleContract:
    target: str
    sample_size: int = 1000
    generator: EnsembleGenerator = EnsembleGenerator.BIOEMU_2
    temperature_kelvin: float = 310.15  # Physiological (37 °C)
    solvation: SolvationModel = SolvationModel.EXPLICIT_EQUIVALENT
    ensemble_id: Optional[str] = None
    max_energy_cutoff_kcal_mol: float = 15.0

    def compute_boltzmann_weight(self, delta_g_kcal_mol: float) -> float:
        """Computes P_i proportional to exp(-Delta G / (k_B * T))."""
```

### 2. `CrypticPocketContract`
Defines transient cryptic binding cavities opening under equilibrium fluctuations:

```python
@dataclass
class CrypticPocketContract:
    pocket_id: str
    target_ensemble: str
    residues: list[int]
    probe_radius_angstrom: float = 1.4
    min_boltzmann_weight: float = 0.05
    max_delta_g_relative_kcal_mol: float = 2.5
    is_transient: bool = True
    target_pathogen_domain: Optional[str] = None

    def evaluates_druggability(self, observed_boltzmann_weight: float, observed_delta_g: float) -> bool:
        """Evaluates whether cryptic opening satisfies thermodynamic druggability criteria."""
```

### 3. `ThermodynamicBindingContract`
Formalizes allosteric stabilization and conformational selection for VHH nanobodies, GPCRs, and de novo binders:

```python
@dataclass
class ThermodynamicBindingContract:
    binder_id: str
    target_ensemble: str
    stabilized_state_condition: str  # e.g., 'tm6_displacement >= 10.0'
    min_target_fraction: float = 0.80
    max_delta_delta_g_kcal_mol: float = -2.0  # Favorable relative stabilization energy
    binding_pocket_id: Optional[str] = None
    temperature_kelvin: float = 310.15
```

## Validation & Verification

All contracts are validated by `EnhancedSemanticValidator`:
- Enforces physical parameter domains ($T > 0\text{ K}$, sample size $> 0$, $0 < P_{\text{Boltzmann}} \le 1.0$).
- Compatibility matrix integration for `bioemu2` across `structural_ensemble_generation`, `cryptic_pocket_detection`, and `thermodynamic_refinement`.
- Fully covered by unit tests in `tests/unit/test_bioemu2_boltzmann_ensembles.py`.
