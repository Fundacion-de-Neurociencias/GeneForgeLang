# Quality bar: GeneForgeLang

Owner directive (2026-10-18): professional, high-quality products. "It works" is not enough; aim for the best standards and the best architecture. This file lists what GFL commits to as a public open-source Python library and CLI. Every standard has a check that proves it. The evaluator runs the applicable checks for each feature (rubric G9). Gaps become features with a target design and a migration path, not patches.

## Target design and migration path (summary)
1. **Hygiene first** (F001-F003): stop the bleeding without changing behaviour.
2. **Provenance contract** (F004) before more simulated code lands with the chain slices.
3. **Integrate as-is, then refactor** (F005-F009): slices preserve the chain's behaviour, with labels added. Refactors happen afterwards so reviews stay readable.
4. **Facade over core** (F010): new `api`/`types`/`contracts` modules re-export from `core`. Old import paths keep working with DeprecationWarning for one minor release, then go private.
5. **Plugins** (F013): one entry-point group, a versioned `Protocol`; the old group is read with a warning for one minor release.
6. **HTTP apps** (F016): moved out of the library or hardened behind an optional extra, according to the owner's decision.
