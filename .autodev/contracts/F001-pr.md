# PR draft: F001 - remove tracked secrets and pickle artifacts; add gitleaks guard

Title: `fix(security): remove tracked secrets file and pickle model; gitleaks in pre-commit and CI [F001]`
Base: `main`. Head: a branch cut from `origin/main` carrying only the product commits of `autodev/F001` (`e793288`, `2cec236`, `11b9118`); no `.autodev/` path. Opening it is an owner gate.

## What it does

- Stops tracking `.devcontainer/.env` and adds `.devcontainer/.env.example` with variable names only (`GOOGLE_API_KEY`, `PYTHONPATH`, `GFL_ENV`).
- Ignores `.env`, `.env.*`, `*.pkl`, `*.pickle` and `*.joblib`; `*.env.example` stays tracked.
- Deletes `resources/tools/genetics/genetic_risk_predictor.pkl` and the two scripts that wrote and loaded it. ADR `docs/decisions/20261019-no-pickle-artifacts.md` records the rule: no code-executing serialization artifacts in the repository or the package.
- Adds secret scanning at two layers with the same rules (`.gitleaks.toml`, gitleaks upstream defaults):
  - pre-commit hook `gitleaks` v8.24.3 on staged changes;
  - workflow `.github/workflows/secret-scan.yml` (job `gitleaks`) on pull requests and pushes to `main`. It scans the commit range and the tree, and fails on any finding.
- Adds `tests/security/test_repository_hygiene.py` (16 tests): no tracked secret or pickle files, ignore rules, no code-executing deserialization, allowlist shape, and pinning of the workflow and hook.

## Why

- `.devcontainer/.env` was public. Its credentials must be treated as leaked: the owner rotates them (list of services kept privately by the maintainers). This PR stops further exposure; it does not rewrite history.
- Loading a pickle runs arbitrary code. The tracked model had unknown provenance, the scripts were broken, and they presented random-data scores as "genetic risk".
- Supply chain (OpenSSF Scorecard practices): `actions/checkout` is pinned by commit SHA, and the token is read-only. gitleaks is a release binary pinned by version and verified against a literal SHA-256. We use the binary instead of `gitleaks/gitleaks-action` because the action needs a license key for organization repositories.
- On pull requests the scan loads `.gitleaks.toml` from the base commit, so a PR cannot widen its own allowlist.
- The allowlist holds the fake-secret fixture directory `tests/fixtures/secrets/` and one exact public value, `nferruz/ProtGPT2` (a Hugging Face model id that the `generic-api-key` rule misreads in `src/geneforgelang/models/advanced_models.py`).
