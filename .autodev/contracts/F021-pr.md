## What it does
- Adds `geneforgelang.public_contract`: builds the public API contract from the code (the 10 functions of `geneforgelang.core.api` with signatures, the public error types and every error code, the grammar constructs, an evidence label per function) and checks it.
- Commits the generated snapshot `docs/spec/public_contract.json` and the rules page `docs/spec/API_CONTRACT.md`.
- Adds `.github/workflows/contract.yml`: `--check` on every pull request, `--against origin/<base>` (version bump and `Contract X.Y.Z` changelog line), and `--check-tag` on `vX.Y.Z` tags.
- `get_api_info()` reports `CONTRACT_VERSION` and `GRAMMAR_VERSION` instead of a fixed `0.1.0`.
- Fixes a flaky timing test cause in `ir/fase4/async_retrieval.py` (`time.time()` to `time.perf_counter()`).

## Why
Clients (GeneForge, PharmaOracle) need a declared surface. A change that would break them must fail here first. Feature F021.

## How to reproduce
```
uv run --no-project --python .venv python -m geneforgelang.public_contract --check
uv run --no-project --python .venv python -m pytest tests/contract -q -p no:cacheprovider
uv run --no-project --python .venv python -m pytest tests -q -p no:cacheprovider
```
Full suite: 1026 passed, 22 skipped, 10 xfailed. ruff clean.
