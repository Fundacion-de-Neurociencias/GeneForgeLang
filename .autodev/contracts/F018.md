## Root causes (per failing test)
1. `tests/unit/test_performance.py::TestIntelligentCache::test_lru_eviction`
   - Symptom: `cache.get("key1")` returns `None` after `put(key3)`; key1 was evicted instead of key2.
   - Root cause: `LRUEvictionPolicy.select_victim` ordered entries by `last_accessed = time.time()`. In this `.venv` (CPython 3.11 on Windows) `time.time()` is `GetSystemTimeAsFileTime()` with 15.625 ms resolution, so `put(key1)`, `put(key2)` and `get(key1)` share one timestamp; `min()` breaks the tie by insertion order and evicts key1. CPython 3.13+ uses a precise clock on Windows, which is why the failure depends on the 3.11 pin; the defect is still real on any platform (ties within one tick, and `time.time()` is adjustable and can go backwards).
   - Fix: per-cache monotonic access counter (see Scope).
2. `tests/unit/ir/test_external_connectors.py::TestOpenMedConnector::test_find_similar_entities`
   - Symptom: similarities `1.0000000000000033` (BRCA1) and `1.0000000000000002` (KRAS) for TP53.
   - Root cause: `dot / (|a|·|b|)` in floating point exceeds 1 for parallel vectors (the mock embeddings are constant vectors, all parallel). By Cauchy-Schwarz |cos| ≤ 1, so values outside are rounding error.
   - Fix: clamp to [-1, 1]. The clamp guarantees [-1, 1], not [0, 1]: `find_similar_entities` returns values in [0, 1] here only because the mock embeddings are positive.
   - Why CI never showed it: the test was skipped when `CI=true` with the reason "requires external network access", which is false (the connector makes no network call; `grep -n "requests\|http\|urllib"` finds only the unused `base_url` default). The skip is removed so the test runs everywhere.

## Deeper version
1. Professional's move: a numerical/systems engineer fixes the invariant, not the test timing: recency is a total order independent of clock resolution, and a similarity metric honours its mathematical bound. Each fix is proven by a test that reproduces the original failure deterministically on every OS (frozen clock), not only on Windows/3.11.
2. Rawest material: the actual failing values (`1.0000000000000033`), the clock info of the pinned interpreter (`resolution=0.015625`), and the CI skip that hid one failure.
3. Methods: clock freezing via `monkeypatch`; boundary tests across nine magnitudes plus seeded random vectors; running the new tests against the old code; repeat-run loop.
4. External oracle: the Cauchy-Schwarz bound (|cos| ≤ 1) and the textbook LRU definition (evict the entry accessed longest ago in access order). The new tests encode both and fail on the pre-fix code (`oracle-old-code.log`).
