# F004 contract: provenance contract for simulated output

Feature: introduce a typed provenance contract and use it to label and disconnect every simulated component on this branch from decisions and public text. Quality bar: QB-3, QB-6. Owner decision 4: nothing is promoted to real without the real service and an oracle test.

## Scope

Changes:
- New `src/geneforgelang/provenance.py`: `Provenance` (frozen dataclass: `kind`, `source`, `version`), `ProvenanceKind`, `SimulatedComponentWarning`, `SimulatedInputError`, `ProvenancedDict` / `ProvenancedList` (dict and list subclasses carrying `.provenance`), `register_simulated_component`, `list_simulated_components`, `warn_first_use`, `reset_first_use_warnings`, `provenance_of`, `require_real_inputs`, `inherit_provenance`.
- Label and warn on first use: `plugins/builtin/protein_generator.py` (random, `simulated`), `plugins/builtin/simple_optimizer.py` (random, `simulated`), `plugins/alpha_genome.py` (`stub`), `plugins/alphafold.py` (byte-for-byte duplicate of `alpha_genome.py` under a misleading name; it becomes a re-export so there is one implementation), `ir/external/openmed_connector.py` (`stub`), `utils/example_implementations.py` (three plugins with random output, `simulated`; found while scoping, not in the feature's file list), `examples/real_project/execute_genesis_real.py` (random scores, `simulated`).
- Decision paths: `core/execution.py` (`execute_design_block`, `execute_optimize_block`, `execute_gfl_ast`) and the public `core/api.py::execute` take `allow_simulated: bool = False` and refuse simulated or stub components and inputs otherwise; allowed output inherits `kind='simulated'`.
- OpenMed: the constant `privacy_cleared` becomes `False`; provenance `stub`; docs state that no privacy guarantee exists.
- Public contract (F021): `CONTRACT_VERSION` 1.0.0 to 1.1.0 (new optional parameter, new public classes `Provenance`, `SimulatedComponentWarning`, `SimulatedInputError`), snapshot regenerated, `CHANGELOG.md` `Contract 1.1.0` line.
- Tests: new `tests/unit/test_provenance.py`; `tests/unit/ir/test_external_connectors.py` (the `privacy_cleared` assertion flips, the `source` value changes to `OpenMed (stub)`); `tests/docs/test_public_claims.py` (C17 strict xfail marker dropped, as its comment requires once the flag is gone). Existing tests that call `execute()` with a shipped simulated plugin must now say so (review item 1): `tests/contract/test_public_contract.py::test_simulated_label_on_execute_matches_the_behaviour` and `tests/test_basic_plugin_functionality.py` pass `allow_simulated=True` and assert `provenance.kind == 'simulated'`; the first also asserts the refusal without the flag. `tests/test_basic_functionality.py` and `tests/test_workflow.py` swallow exceptions, so they stay green but silently stop exercising execution; `tests/test_workflow.py` already never executes (stale call signature without a registry). Both are left as they are and recorded in progress.md.
- Docs: `docs/spec/API_CONTRACT.md` (provenance section), `.autodev/system/components.md` (new), README note, `docs/architecture/FASE3.md` and `demo_ir.py` lines that present the privacy flag as granted.

Does not change: parser, validator, grammar, CLI, web apps, `plugin_registry.py` (it stores classes or instances; provenance is a class attribute, visible on both, so no registry change), `llm_planner.py`, manuscript text (the 2026-11-15 delta items for those belong to a later claims feature; they are not on the files this feature lists; recorded in progress.md).

## Done means

Run from the repository root with the project venv (`uv run --no-project --python .venv python -m pytest ...`).

1. **Type and shape.** `Provenance("measured"|"computed"|"simulated"|"stub", source, version)` is frozen; an unknown kind or empty source or version raises `ValueError`. `mypy --strict src/geneforgelang/provenance.py` exits 0 (test `test_provenance_module_passes_mypy_strict`).
2. **Per component.** Seven components register in the package; nine rows exist in `components.md`. Registered (`list_simulated_components()` returns exactly these names): `SimpleProteinGenerator` (simulated), `SimpleOptimizer` (simulated), `AlphaGenomePlugin` (stub; `plugins/alphafold.py` re-exports it), `OpenMedConnector` (stub), `ProteinVAEGenerator`, `MoleculeTransformerGenerator` and `BayesianOptimizer` (simulated, all three in `utils/example_implementations.py`). Extra rows: `execute_genesis_real` (simulated; the script registers itself when run, it is not a package module) and `VariantSimulationPlugin` (`dead`: `plugins/variant_sim.py` needs `simulate_variant_effect.py`, which is not in the repository, so construction raises `FileNotFoundError`; the registry's auto-register path imports the non-existent package `gfl.plugins`, so it never loads). Access: a plugin result is a `ProvenancedDict` or `ProvenancedList`; for dict results both `result.provenance.kind` and `result["provenance"]["kind"]` are asserted. `OpenMedConnector` entities and similar entities carry a `provenance` field and the returned list carries `.provenance`. The example plugins return `DesignCandidate` lists: the list is a `ProvenancedList` and each candidate has `metadata["provenance"]`. In every case `kind in {simulated, stub}`, and `SimulatedComponentWarning` is raised exactly once per component name per process on first use (`OpenMedConnector` warns once for the connector, not once per method) and not on the second call (`pytest.warns`, then `warnings.catch_warnings(record=True)`, after `reset_first_use_warnings()`).
3. **Registry and table.** `list_simulated_components()` rows carry name, kind, location and a non-empty promotion oracle. When `.autodev/system/components.md` exists (it is local-only state, so the test skips on a public clone), its rows have a state in `{simulated, stub, dead}` (never `real`) and a non-empty oracle, and every registered name appears in it.
4. **Completeness oracle (external, not written from the component list).** An AST scan of `src/geneforgelang` finds every module that, at any nesting level (including imports inside functions), imports `random`, `secrets`, `numpy.random` or `hashlib`, or uses the attribute `np.random` or `numpy.random`. The test asserts set equality between the modules found and `REGISTERED ∪ ALLOWLIST`, so a stale allowlist entry fails too. The allowlist is exactly these modules, each with a written reason: `core/parser.py`, `core/performance.py`, `core/enhanced_inference_engine.py`, `plugins/plugin_registry.py`, `governance/behavioral/semantic_hash.py`, `ir/fase4/cache_layer.py` and `ir/fase4/async_retrieval.py` (all use `hashlib` only to build cache or content keys; no output value derives from the hash). `ir/external/openmed_connector.py` is registered, not allowlisted, although it also uses `hashlib` (there the hash derives the returned vectors). Limit: components that return constants without importing a stochastic primitive (`AlphaGenomePlugin`, a stub) are not seen by this oracle; only the registry list covers them. Mutation: a copied tree with `import random` added to a scratch module makes the test fail; evidence saved.
5. **Decisions refuse.** `execute_optimize_block`, `execute_design_block`, `execute_gfl_ast` and `geneforgelang.execute` call `require_real_inputs` on the plugin (class or instance), the block's parameters and the engine's `workflow_state`. A simulated input is any plugin, result or nested value in those objects whose `provenance_of(...)` is `simulated` or `stub`. The parsed AST is a plain dict and carries no label, so refusal there comes from the plugin and from `workflow_state`. Without `allow_simulated=True` they raise `SimulatedInputError`. With `allow_simulated=True` they return, and `provenance_of(result).kind == 'simulated'` on the top-level dict returned by `execute_gfl_ast` (a `ProvenancedDict`; block results keep their own labels). A clean plugin defined in the test with `provenance = Provenance("computed", ...)` and clean inputs runs without `allow_simulated`, and `provenance_of(result) is None` (the engine adds no claim).
6. **No guarantee keys.** An AST test over `src/geneforgelang` and `examples/real_project` finds no dict key, keyword argument or subscript assignment named `privacy_cleared`, `validated` or `calibrated` whose value is the constant `True`, in any quote style (a non-constant value is allowed because it may come from a real check). `OpenMedConnector().deidentify_clinical_note(...)["privacy_cleared"] is False` and `["provenance"]["kind"] == "stub"`. The existing C17 guard passes without its xfail marker.
7. **Public text and contract.** `docs/architecture/FASE3.md` no longer says the flag is `True`; `demo_ir.py` prints the flag with its stub label. `docs/spec/API_CONTRACT.md` has a provenance section naming `Provenance`, `allow_simulated`, `SimulatedInputError`, `SimulatedComponentWarning` and `list_simulated_components` (a docs test checks the names). `python -m geneforgelang.public_contract --check` exits 0 after regeneration, and `--against autodev/integration` (not HEAD, which already contains the change) passes with the 1.1.0 bump and the changelog line.
8. **Example script.** The test calls `pytest.importorskip` for `numpy`, `pandas` and `matplotlib`, sets `MPLBACKEND=Agg` with `monkeypatch.setenv`, loads `examples/real_project/execute_genesis_real.py` with `importlib.util.spec_from_file_location` (`examples/` is not a package), patches `time.sleep` with `monkeypatch` (a clock, not the system under test), calls `simulate_geneforge_engine()`, and asserts that `json.dumps(result, default=str)` works, that `result["provenance"]["kind"] == "simulated"` and `result.provenance.kind == "simulated"`, and that `SimulatedComponentWarning` is raised once.
9. **Type check.** `mypy --strict --no-incremental --config-file= src/geneforgelang/provenance.py` exits 0. The empty config avoids `mypy.ini`, whose `python_version = 3.9` the installed mypy rejects and whose lax settings are not strict. The test puts the mypy version in its failure message and skips only if mypy is not installed. Python 3.9 syntax is checked by importing the module under `uv run --python 3.9` (evidence file).
10. **Suite.** Baseline before the change, saved as `evidence/F004/baseline.log`: 1035 passed, 23 skipped, 10 xfailed. After: 0 failed, 0 errors, xfailed equals baseline minus one (C17), passed at least baseline. `ruff check src tests` exits 0. `language_check.py --diff autodev/integration` reports 0 segments.

## Assumptions (falsifiable)

- A1. `registry.get_generator()` / `get_optimizer()` return what was registered (a class or an instance), and a class attribute `provenance` is visible on both. Falsified if a registry path wraps plugins in a proxy.
- A2. No test or caller depends on `privacy_cleared` being `True` other than `test_deidentify_clinical_note`. (grep: `demo_ir.py` prints it, `FASE3.md` documents it.)
- A3. Python 3.9 stays supported, so the new module avoids `X | Y` at runtime and uses `from __future__ import annotations`.
- A4. `mypy --strict` on the one file checks only that file and what it imports; the new module imports only the standard library. The empty `--config-file=` keeps `pyproject.toml`'s `packages` setting from widening the run (confirmed by the command output naming 1 source file).
- A5. `plugin_registry.py` auto-registers `gfl.plugins.alpha_genome`, a package name that does not exist, so that registration silently fails today. Not fixed here (F013).

## Deeper version

What a top professional does: treat "simulated" as a property that flows with the data, not a comment next to the code.
- Raw material: the code itself (every `random`, hash-derived or constant-returning component), IEEE 2791-2020 (BioCompute Object) provenance vocabulary for the later export (QB-6), and the NeuroIA protocol sections 8 and 8.1 named in the quality bar.
- Methods: a type that carries the label (`Provenance`), taint propagation (a decision over simulated input is simulated), refusal by default with an explicit opt-in, a registry that makes the set of simulated components queryable, and a completeness check that does not trust the author's list.
- Tools: `ast` scan, `pytest.warns`, `mypy --strict`, the F021 contract check, `ruff`.
- External oracle (part of "Done means" item 4): the AST scan over the whole package for the stochastic and hash-derived primitives. It proves the labelling is complete against the code, not against the feature text.

Not claimed: this feature does not prove any component is correct; it only makes the lack of evidence visible and keeps it out of decisions.
